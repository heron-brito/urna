# Efeitos sonoros (SFX)

A sonoplastia segue o espírito do DuoLingo: sons curtos e marcantes.
Os arquivos abaixo são **placeholders** (reaproveitam sons antigos) e
devem ser substituídos por efeitos próprios/livres de direitos:

| Arquivo       | Quando toca                         | Sugestão de som            |
|---------------|-------------------------------------|----------------------------|
| `botao.wav`   | toque em ajudas/botões              | clique curto               |
| `correct.wav` | resposta correta                    | "ding" alegre ascendente   |
| `wrong.wav`   | resposta errada                     | "buzz" curto grave         |
| `tick.wav`    | últimos 5 segundos do cronômetro    | tique-taque                |
| `win.wav`     | chegou a 1.000.000 de coins         | fanfarra de vitória        |
| `fim.wav`     | fim de jogo (derrota)               | som de encerramento        |

Não inclua sons protegidos por direitos autorais (ex.: áudios oficiais do
DuoLingo ou do Show do Milhão). Use bibliotecas livres (freesound, etc.).
